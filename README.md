# Star Shooter

A 2D shooter game created in Raylib (C++) as my final university project.

The game has a gradual increase in difficulty, tracking health and obtained upgrades consistently throughout each, and a boss fight every 10 levels.

While I am proud of the functionality I managed to implement, particularly in regards to the fully-functional UI and upgrades system, in a future project I would touch up the graphics particularly in regards to said UI. I would also want to implement a greater amount of enemies, possibly including an endless mode, and more backgrounds. In regards to the inner workings of the code, while enumerators work well, in the future, a switch would be better than if statements for the gamestate switching. However, I would prefer to implement a scene manager, as while the current system works fine for a small indie game, it introduces substantial variable bloat.
